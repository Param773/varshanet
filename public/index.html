HOW IT WORKS

How a post becomes an alert

Four stages turn an unstructured, unverified post into a trustworthy point on the map.

01
Ingest

Crawl #IMD and weather hashtags across social platforms, citizen app submissions, public datasets and open APIs — capturing text, media, GPS and timestamp as it lands.

02
Verify

Score every report for authenticity, cross-check the source, and cluster near-identical posts so duplicates never reach the map twice.

03
Categorize

Classify each verified report into rainfall, thunderstorm, flooding, heatwave, fog, dust storm or strong winds — automatically, with no manual tagging.

04
Visualize

Plot everything on a live map with date, location and event filters, so analysts see what's happening as it happens.
